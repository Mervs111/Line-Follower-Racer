### 2. Weekly Report Description

Kegiatan selama 1 minggu sesuai tanggal. Ditulis **per poin**, tiap poin ada
**penjelasan singkat**. Kalau ada gambar/tabel, beri **keterangan dan penjelasan**.

### 3. Obstacle(s)

Kendala yang dihadapi dan **belum terselesaikan** selama pengerjaan.

### 4. Documentation

Dokumentasi mingguan (foto/screenshot kegiatan), masing-masing dengan keterangan.
